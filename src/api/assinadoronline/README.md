# Assinador Online API

The Strapi core router exposes the collection at `/api/assinadoronlines`.
The generated REST operations are list, read by `documentId`, create, update,
and delete.

Access is controlled by Strapi. To enable an operation, configure its
permission for the appropriate role under **Settings > Users & Permissions
Plugin > Roles**. Do not enable public access unless the endpoint is intended
to be unauthenticated.

The collection schema is in `content-types/assinadoronline/schema.json`.
